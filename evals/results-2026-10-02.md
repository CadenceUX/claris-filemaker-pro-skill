## Fixed in response

- HMAC pattern now compares with `Exact()` — FileMaker's `=` ignores case (engine-confirmed:
  `"abcD" = "ABCd"` → 1). A signature differing only in case would have passed. Security-relevant.
- The remaining `Abs ( PMT ( … ) )` example removed (contradicted the "positive" rule).
- SKILL.md: gotchas for `=` vs `Exact()` and `Choose` vs `Case`; engine-only steps now carry a
  **MUST** caveat; engine version read from `filemaker --help` (not `--version`).
- `adt-mode.md`: find Claris pages in the **installed** ADT version (the cache holds older ones).
- `data-api-reference.md`: `scriptResult` / `scriptError` response and script order.
- `webdirect-reference.md`: the full No / Partial step lists written out, for hosts without a shell.

checklist the model copies at the start, not only in a reference file or a gotchas list.
